{% comment %} Displays a user's profile photo. Pass a user explicitly when rendering someone else's profile: `{% include "partials/avatar.html" with avatar_user=profile_user %}`. Without it, the partial falls back to the current `user`. `avatar_user.profile.avatar_url` prefers an uploaded photo, then the `picture` URL allauth stores on a linked Google account. The initial covers email-only users who have not uploaded anything yet. {% endcomment %} {% with avatar_user=avatar_user|default:user %} {% with avatar_url=avatar_user.profile.avatar_url %} {% if avatar_url %} {% else %} {{ avatar_user.get_full_name|default:avatar_user.email|first|upper }} {% endif %} {% endwith %} {% endwith %}
